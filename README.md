# Nova site

Static source for [aoweichenn.github.io](https://aoweichenn.github.io/), a public introduction to the Nova project.

- `/` — overview and navigation
- `/about/` — project idea and design principles
- `/design/` — high-level runtime and interface design
- `/progress/` — prototype status and next steps

Nova's implementation repository is private. This site describes the design direction and prototype status only. Edit the HTML and `style.css`, then push to `main` to publish through GitHub Pages.
