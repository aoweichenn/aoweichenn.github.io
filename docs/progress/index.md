# 目前的进展

Nova 有 C++20 Host、TypeScript Web，以及 TUI 和 CLI 的原型入口。设计文档已经形成评审稿，代码还在按这些约定调整。

## 已经有的

- 可以继续迭代的运行时和多端原型。
- 一批针对具体场景的测试与验证记录。
- 关于状态、工具和客户端边界的设计文档。

## 还在做的

恢复、取消、工具结果和多端一致性等路径仍在持续完善。当前原型不能当作已经验收的完整产品，也没有正式发布时间。

这页只给一个简短摘要。想知道为什么我把“原型”和“完成”分开说，可以读 [Nova 现在到哪一步了](/posts/prototype-is-not-product)。
