# Nova 的进展

Nova 目前处于**设计与原型迭代阶段**。已有 C++20 Host、TypeScript Web，以及终端工作台和脚本 CLI 的原型入口。整体架构仍在按设计契约修复和扩展，不能把当前源码当作完整目标架构或正式产品。

## 已有基础

- 项目形成了分层设计评审稿，明确运行时、界面和工具边界的目标。
- C++20 与 Web 原型可以作为后续迭代的基础。
- 终端与脚本入口已有原型路径，仍需继续完善体验和边界验证。

## 正在推进

状态、恢复、工具结果、跨端一致性等问题仍在持续实现与回归。项目会把设计要求与当前实现分开记录，先说明可验证的范围，再谈完成度。

## 尚未宣称

本站不宣称 Nova 已完成生产级交付、已覆盖全部设计目标，或已经完成真实模型与所有客户端的统一验收。

想了解为什么保持这种表述，可以读 [原型不等于产品](/posts/prototype-is-not-product)。
