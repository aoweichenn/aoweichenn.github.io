# Web、TUI、CLI 共用一个 Host

<PostMeta date="2026-10-27" :tags="['Nova', '架构']" />

Nova 有三个入口：网页、终端工作台和脚本 CLI。它们看起来不一样，但背后处理的是同一个会话。如果每个入口都自己保存进度，很快就会出现“网页显示完成，终端还在等待”的情况。

所以我把 Host 放在中间。会话、Agent 和工具调用由它管理；客户端负责展示和提交操作。这个分工听起来简单，做起来要照顾不少边界。

## 网页和终端

网页适合看会话列表、文件和较长的工具输出。TUI 适合一直待在终端里，用键盘切换和输入。两者都需要在断开后重新跟上 Host 的状态，不能只相信自己内存里最后一次看到的内容。

## 脚本入口

CLI 经常被其他命令调用。对脚本来说，“请求已经交给 Host”与“任务已经完成”是两种不同的结果。超时、Ctrl-C 和回执丢失也要有明确说法，否则上层脚本没法决定是否重试。

## 还在补的地方

现在三个入口都有原型，但完整体验还没做完。我会继续检查它们在取消、重启和状态恢复时是不是说同一件事。更简短的结构图在 [设计页](/design/)，当前范围在 [进展页](/progress/)。
