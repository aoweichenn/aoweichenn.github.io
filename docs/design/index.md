# 设计草稿

Nova 现在的结构可以粗略画成这样：

```text
Web ─┐
TUI ─┼──> Host ──> 会话、Agent、工具
CLI ─┘
```

三个客户端负责不同的使用方式，Host 负责会话和任务状态。这样做是为了避免每个客户端各自维护一套进度。

## 三个入口

| 入口 | 主要用途 |
| --- | --- |
| Web | 看会话、文件和较长的输出。 |
| TUI | 在终端里切换会话、输入和查看状态。 |
| CLI | 从脚本或命令行提交任务并读取结果。 |

这只是高层结构，不代表每一条交互路径都已经做好。取消、超时、重启和多端切换时的行为还在继续补。更具体的说明见 [Web、TUI、CLI 共用一个 Host](/posts/one-runtime-three-surfaces)。
