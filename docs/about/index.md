# 关于这个博客

这里是 Aowei 的公开开发笔记。第一组文章围绕 **Nova**：一个以 C++20 运行时为核心、面向 Web、终端工作台和脚本 CLI 的 AI Agent 工作台。

我想把项目做成什么、为什么这样设计，以及哪些地方还没验证清楚，都写在这里。文章会区分**设计目标**与**当前原型**，避免把草图写成已经交付的功能。

## 从哪里开始

- 想快速了解项目：读 [Nova 项目介绍](/nova/)。
- 想看所有文章：去 [文章归档](/posts/)。
- 想知道当前状态：看 [项目进展](/progress/)。

本站由 Vue 和 VitePress 构建，源代码公开在 [GitHub](https://github.com/aoweichenn/aoweichenn.github.io)。Nova 的实现仓库目前是私有的；本站只记录适合公开的方向与进展。
