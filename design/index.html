THE SURFACES

三种使用方式。

不同入口服务不同场景，核心仍保持一致。

01 / WEB

在网页里看全局

用图形界面整理会话、任务与工具活动，适合持续观察和操作。

▤
02 / TUI

在终端里保持专注

让熟悉键盘工作流的人，在终端中跟随同一份会话状态。

⌘
03 / CLI

把任务接进脚本

用命令行入口发起和观察工作，便于与已有流程组合。
